This project studies the interaction between large data-center loads, grid-forming resources, and dynamic hosting capacity. The work evaluates how controllable load behavior and grid-forming capability can affect frequency, voltage, and transient security under stressed grid conditions.

The analysis combines dynamic simulation, contingency screening, and operational security metrics to assess how much flexible data-center capacity can be safely hosted.

**Keywords:** grid-forming inverters, dynamic hosting capacity, data centers, frequency security, voltage stability, transient response.
