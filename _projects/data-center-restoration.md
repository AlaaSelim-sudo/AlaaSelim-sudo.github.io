This project studies how large data centers can participate in power-system restoration without being treated as conventional blackstart units. The framework models data centers as restoration-compatible assets whose local resources and flexible IT operation can be coordinated with system-level restoration needs.

The current work evaluates how different coordination policies change restored load, unserved energy, early export support, and preservation of critical IT service. Recent results include IEEE 39-bus and IEEE 300-bus validation, policy-ablation analysis, stress-robustness testing, productivity-aware site prioritization, and scalability evaluation.

**Keywords:** blackstart restoration, data centers, large flexible loads, grid resilience, optimization, critical service preservation.
