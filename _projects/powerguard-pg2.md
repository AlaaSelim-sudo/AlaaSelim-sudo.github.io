PowerGuard PG2 is a cyber-physical defense project for smart-grid communication and control environments. The work focuses on detecting abnormal commands and coordinating safe recovery using protocol-level, topology-level, and physics-level evidence.

The framework is designed for realistic grid settings where communication behavior, network topology, and electrical constraints must be considered together before a control action is trusted.

**Keywords:** cyber-physical security, SDN-enabled grid defense, Modbus security, grid communication, physics-informed mitigation.
