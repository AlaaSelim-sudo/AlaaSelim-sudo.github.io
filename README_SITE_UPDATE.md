# GitHub Website Update Package

Copy these folders into your GitHub Pages repository:

```text
AlaaSelim-sudo.github.io/
```

## What this package includes

- `_pages/group.md` — new group page with members classified by university.
- `_pages/research.md` — research page with explanatory figures.
- `_pages/cv.md` — cleaned CV page metadata.
- `_data/cv.yml` — updated structured CV data from the uploaded CV.
- `_projects/*.md` — project pages for data centers, PowerGuard PG2, P2P Protocol, GridGuard, and GFM data-center flexibility.
- `_news/*.md` — initial news updates.
- `assets/img/*.svg` — simple professional research figures used by the pages and projects.

## How to use with GitHub Desktop

1. Open your website repo in GitHub Desktop.
2. Click `Repository` → `Show in Explorer` or `Open in Visual Studio Code`.
3. Copy the folders from this package into your repo.
4. Allow files to replace old versions when asked.
5. In GitHub Desktop, write a commit message:

```text
Update website projects group research and CV
```

6. Click `Commit to main`.
7. Click `Push origin`.

Then check:

```text
https://AlaaSelim-sudo.github.io
```
